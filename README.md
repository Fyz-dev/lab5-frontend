# Task Manager (Todo App)

Лабораторна робота №5 з дисципліни Frontend, присвячена роботі з DOM, подіями JavaScript та взаємодії з REST API за допомогою Fetch API, Promises і async/await.

## Опис

Проєкт являє собою інтерактивний вебзастосунок для керування списком завдань (Task Manager / Todo App). Застосунок дозволяє завантажувати завдання з сервера, створювати нові, змінювати їх статус, видаляти та шукати необхідні завдання.

У процесі виконання лабораторної роботи реалізовано маніпуляцію DOM-елементами, делегування подій, обробку форм і клавіатури, асинхронні HTTP-запити та роботу з REST API JSONPlaceholder.

## Особливості

### DOM та робота з інтерфейсом

- Динамічне створення елементів за допомогою `document.createElement()`
- Додавання елементів через `append()`
- Використання `querySelector()` та `querySelectorAll()`
- Робота з `dataset` для зберігання ідентифікаторів завдань
- Додавання та видалення CSS-класів через `classList`
- Динамічне оновлення DOM без перезавантаження сторінки

### Події

- Обробка подій через `addEventListener()`
- Обробка відправки форми з використанням `preventDefault()`
- Делегування подій для списку завдань
- Обробка кліків по чекбоксах і кнопках видалення
- Підтримка клавіш:
  - `Enter` — додавання завдання
  - `Escape` — очищення поля введення
- Пошук завдань із використанням `debounce`

### Робота з API

- Отримання завдань через `GET`
- Створення завдань через `POST`
- Оновлення статусу та назви через `PATCH`
- Видалення завдань через `DELETE`
- Одночасне завантаження даних через `Promise.all()`
- Робота з JSONPlaceholder API

### Асинхронне програмування

- `Promises`
- `async/await`
- `try/catch/finally`
- Обробка помилок мережевих запитів

### Додатковий функціонал

- Фільтрація завдань:
  - Всі
  - Активні
  - Виконані
- Пошук завдань за текстом
- Лічильник активних завдань
- Індикатор завантаження під час запитів до API
- Блокування кнопки додавання при порожньому полі введення
- Відображення повідомлень про помилки
- Інлайн-редагування назв завдань подвійним кліком (додаткова функція)

## Реалізовані HTTP-запити

| Метод  | Призначення                          |
| ------ | ------------------------------------ |
| GET    | Завантаження списку завдань          |
| POST   | Створення нового завдання            |
| PATCH  | Оновлення статусу або назви завдання |
| DELETE | Видалення завдання                   |
